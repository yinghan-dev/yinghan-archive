# ✨yinghan-archive

这是一个个人博客项目，创建于2025年8月，当时只会vibecoding，网页也写的很冗杂，最近重新把这个项目捡起来了，凭借一些好奇心和兴趣，我在努力学习前端内容，并不断优化旧版代码。这里记录我在学习、实践探索中留下的各种痕迹。

它并不是一个复杂的项目，仅仅是一些HTML/CSS/JavaScript的应用，就博客本身内容来说，它记载着我作为研究生最朴实而真实的生活，我不想要太多喧嚣，只想在自己的世界里岁月静好。

## 📁 Project Structure

```
yinghan-archive/
├── articles/       # 文章与文字内容
├── css/            # 样式文件
├── data/           # 页面数据与内容数据
├── images/         # 图片及其他媒体资源
├── js/             # JavaScript 脚本
├── lib/            # 第三方库及相关资源
├── article.html    # 文章页面
├── index.html      # 主页
├── CNAME           # 自定义域名配置，之前有过域名，等过几个月会申请个新的
├── LICENSE         # MIT License
└── README.md
```
项目目录一目了然，如果觉得设计美观可以给个star或者fork，文章和照片不算很隐私，但也不希望被不礼貌对待。
